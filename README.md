# NIDAR Production Drone Software

NIDAR is a safety-first companion-computer flight application for a CUAV X7+ running PX4. PX4 retains ownership of stabilization, low-level control, state estimation, flight modes, and failsafes; the Raspberry Pi 5 application will provide mission orchestration and PX4-approved high-level setpoints.

Phase 0 establishes the repository and project contracts only. It contains no PX4 integration, vehicle commands, simulator configuration, or flight logic.
